# Familiar Roadmap

These are features we would like to explore and improve. Their order may change, and there are no promised release dates.

## Extract a Color Palette from an Image

Pick an image on the board and extract its main colors into a palette. Make the colors easy to inspect and copy for use in other design tools, with room to adjust the selection. Inspired by [Adobe Color's image palette tool](https://color.adobe.com/create/image). [Follow the discussion on GitHub](https://github.com/try-hard-factory/familiar/issues/102).

## Make the Interface Beautiful

Polish the window controls, icons, cursors, settings, and light and dark themes. Keep the interface clear and comfortable to use across different screen sizes and scaling settings. [Follow the discussion on GitHub](https://github.com/try-hard-factory/familiar/issues/128).

## Multiple Windows and Safe Project Access

Work with boards in separate windows. If a project is already open, bring its window or tab forward instead of opening another editable copy. Handle a second launch of Familiar safely, too. [Follow the discussion on GitHub](https://github.com/try-hard-factory/familiar/issues/124).

## View 3D Models on the Canvas

Place a 3D model on a board and enter an interactive mode to rotate it, zoom, and move the camera. Preserve the model and its view when the project is saved. [Follow the discussion on GitHub](https://github.com/try-hard-factory/familiar/issues/122).

## Command Palette

Find and run Familiar's actions by typing, with current keyboard shortcuts shown beside the results. [Follow the discussion on GitHub](https://github.com/try-hard-factory/familiar/issues/121).

## Import Folders

Drag a folder onto a board or choose one in a file dialog to add its supported images. Show progress and make it possible to cancel a large import. [Follow the discussion on GitHub](https://github.com/try-hard-factory/familiar/issues/120).

## Suggest a Feature

Feature requests are welcome. [Open a GitHub issue](https://github.com/try-hard-factory/familiar/issues) or [share your idea on Discord](https://discord.gg/3672sNT5qA).
